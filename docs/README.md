# docs/ · dokumen Tugas Besar kelompok

Folder ini milik kelompok. Starter Laravel **tidak** membawa dokumen apa pun:
kelompok tetap memakai dokumen yang sudah ditulis di repo `tb-kelNo` sejak
P9 (kebutuhan, keputusan, arsitektur, ADR), P10 (pengujian), dan P11
(runbook, postmortem latihan), lalu menambah dokumen P12–P15 di sini.

Saat pindah ke starter (README, bagian "Pindah dari buku tamu"), folder
`docs/` lama disalin utuh ke sini. Perbarui bagian yang menyebut buku tamu
PHP (diagram container, ADR aplikasi, Tabel 1 uji fungsional) lewat pull
request, dan catat perpindahan ini sebagai ADR baru.

Contoh bentuk dan isi dokumen lengkap: repo contoh dosen `tb-kel0`.
